## 2. PLC 将接收的规程力转换为力控目标力并经 RSI 下发

在 PLC 上将上位机接收到的规程力转成力控的目标力，通过 RSI 网络提供给力控上位机程序。

PLC 侧（SCL）处理：REAL 转 DINT/DWORD 后，按已调对的字节顺序拆成 4 字节写入发送数组：

```scl
// 1. 转为整型 DINT
#tempDWord := DINT_TO_DWORD(REAL_TO_DINT("DB1900_Communication_PC".Para.Auto_Force[1]));

// 2. 写入 4 字节数组（保持当前已调对的对应顺序）
"DB720_KuKa_MainCtrl".CmdOut.SP[1] := #tempDWord.%B0;
"DB720_KuKa_MainCtrl".CmdOut.SP[2] := #tempDWord.%B1;
"DB720_KuKa_MainCtrl".CmdOut.SP[3] := #tempDWord.%B2;
"DB720_KuKa_MainCtrl".CmdOut.SP[4] := #tempDWord.%B3;
```

字节对应关系：`SP[1]↔%B0`、`SP[2]↔%B1`、`SP[3]↔%B2`、`SP[4]↔%B3`（低字节在前），此顺序为现场已调对的顺序，勿随意调整。
